# Badminton-Timetable-Solver

## Overview

This project implements a tournament scheduling system using MiniZinc for constraint programming and Python for data handling, Excel output, and orchestration.

The scheduler assigns matches to time slots and fields, ensuring finnish badminton tournament rules are followed. 

This project is specifically designed for tournaments with multiple classes, rounds, and collision constraints between classes.

## Requirements
Python 3.10+

MiniZinc 2.8+

Install dependencies with

pip install -r requirements.txt
